# EMF Payroll Online

Even More Foods Private Limited – Online Payroll & Attendance System

## Live App
Open: https://santhakumaremf-cpu.github.io/emf-payroll/

## Features
- Add / Edit / Delete workers
- Day-wise attendance marking (click cells)
- Salary calculation (PF, ESI, Advance, Net)
- Advance management
- Export CSV / JSON backup
- Data saved in browser (localStorage)
- Works offline after first load

## How to use
1. Open the link above on any phone or computer
2. Employees tab – Add Worker button
3. Attendance – click any day cell to cycle Present / Absent / Leave
4. Settings – Backup JSON to move data to another device
